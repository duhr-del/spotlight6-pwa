# Английский в фокусе 6 — игровой тренажёр (PWA)

Тренажёр английского языка по темам учебника «Английский в фокусе / Spotlight 6» (Ваулина, Дули, Подоляко, Эванс).
Один пользователь, без бэкенда и платных сервисов. Работает в браузере на Android-планшете и на ноутбуке,
устанавливается на рабочий стол как приложение, после первой загрузки работает офлайн (кроме микрофона).

**Что внутри:** 10 модулей с подмодулями (1a, 1b, 1c, 1d), 665 слов с транскрипцией, 262 фразы для конструктора,
257 текстов для чтения, три режима, звёзды и прогресс в `localStorage`.

## Что нового в версии 1.1

**Режим проверки написания — словарный диктант.** Кнопка «✍️ Слушай и пиши» открывает режим, в котором
слово **произносится вслух**, но его **написание и транскрипция скрыты** — ребёнок пишет по слуху, а не копирует
увиденное. В панели ввода есть кнопка «🔊 Повторить», чтобы послушать слово ещё раз. После верного ответа
слово показывается в сообщении обратной связи.

**Визуальная обратная связь озвучки.** Во время воспроизведения слова кнопка «Слушать» показывает состояние
«🔊 Играет…» с подсветкой — ребёнок видит, что звук идёт.

**Починки по результатам ревью:**

- `scripts/validate_content.py` — хардкод Windows-пути заменён на относительный через `__file__`. Скрипт
  работает на любой ОС. Проверяет секционную структуру, повторы слов между секциями, согласованность
  `words` и `en`, наличие транскрипций. Проверка словаря в чтении — предупреждение (не блокирует).
- `scripts/make_icons.py` — список шрифтов расширен для macOS и Linux, fallback через `fc-match`.
- `js/app.js` — `render()` обёрнут в `try/catch` (error boundary).
- `js/modes/builder.js` — перемешивание повторяется, пока порядок не совпадёт с правильным.
- `js/modes/reading.js` — `trim()` перед `split(/\s+/)` от рассинхрона флагов.
- `js/storage.js` — `migrate()` для версионирования прогресса; чистка повреждённых записей.

## Быстрый старт

Приложение статическое, сборка не нужна, `npm install` не требуется. Но открывать `index.html` двойным
щелчком **нельзя**: браузер блокирует ES-модули и загрузку JSON с `file://`, а Service Worker требует
`http://localhost` или HTTPS. Запустите любой локальный сервер из папки проекта:

```bash
python -m http.server 5173
# откройте http://localhost:5173
```

Альтернативы: `npx serve .`, `php -S localhost:5173`, расширение Live Server в VS Code.
На Windows можно просто дважды щелкнуть `start-server.bat` — он поднимает Python-сервер и открывает браузер.

## Установка как приложение

- **Android (Chrome):** открыть адрес по HTTPS → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **Ноутбук (Chrome/Edge):** в адресной строке появляется иконка установки, либо меню → «Установить Английский в фокусе 6».
- После установки приложение открывается в отдельном окне без адресной строки.

Важно: установка и микрофон работают только на `https://` или `http://localhost`. Если открыть файл с диска
или по `http://192.168.x.x`, Chrome не даст доступ к микрофону и не предложит установку.

## Режимы

| Режим | Что делает | Звёзды |
|-------|-----------|--------|
| **Словарные карточки** | перевод, озвучка; **проверка написания — словарный диктант**: слово произносится, но написание и транскрипция скрыты, ребёнок пишет по слуху; проверка произношения (для длинных слов) | до 2 за слово: 1 за написание + 1 за произношение |
| **Собери предложение** | русская подсказка, чипы вперемешку, проверка порядка, озвучка готовой фразы | 2 за верно собранную фразу |
| **Проверка чтения** | образец голосом, чтение вслух, процент распознанных слов и подсветка | 3 при ≥90%, 2 при 70–89%, 1 при 50–69% |

Звёзды не накапливаются счётчиком: они выводятся из состояния каждого слова и фразы, поэтому повторным
прохождением накрутить их нельзя. «Освоено» = слово закрыто и на написание, и на произношение
(для служебных слов без произношения — только написание).

## Контент и как его править

Всё содержимое лежит в `data/*.json` — код менять не нужно. Каждый модуль делится на подмодули-секции (1a, 1b, 1c, 1d):

```json
{
  "id": "module3",
  "title": "Модуль 3. Getting around",
  "color": "#C0873E",
  "sections": [
    {
      "id": "3a",
      "title": "3a. Road safety",
      "words": [
        { "en": "bus stop", "transcription": "/ˈbʌs stɒp/", "ru": "автобусная остановка" },
        { "en": "at", "transcription": "/æt/", "ru": "в (о времени)", "noSpeak": true }
      ],
      "sentences": [
        { "ru": "Я хожу в школу пешком.", "en": "I go to school on foot.",
          "words": ["I", "go", "to", "school", "on", "foot"] }
      ],
      "reading": ["I go to school on foot."]
    },
    { "id": "3b", "title": "3b. On the move", "words": [...], "sentences": [...], "reading": [...] }
  ]
}
```

Правила:

- `sections[]` — массив подмодулей; каждый имеет `id` (например `"3a"`), `title`, `words`, `sentences`, `reading`.
- `words[].en` — то, что ребёнок видит и печатает; `transcription` — IPA в косых чертах; `ru` — перевод.
- `noSpeak: true` отключает проверку произношения для коротких служебных слов (`at`, `in`, `on`, `can`, `must`).
  Для них максимум 1 звезда.
- `sentences[].words` должен совпадать с `en`, разбитым по пробелам, без завершающей точки. Если массив
  не указан, приложение разобьёт строку само.
- `reading` — отдельный список фраз для чтения; если его нет, возьмутся первые 10 фраз конструктора секции.
- Прогресс хранится по `moduleId + word.en`, поэтому слова можно перемещать между секциями — прогресс не теряется.

**Добавить модуль 11:** положить файл `data/module11.json` (структура — как выше, с `sections`), добавить строку
в `data/modules.json` (`{"id": "module11", "order": 11, "title": "...", "color": "..."}`), добавить путь
к файлу в `PRECACHE` в `service-worker.js` и поднять `VERSION`.

Проверка контента после правок:

```bash
python scripts/validate_content.py
```

Она проверяет валидность JSON, количество элементов, отсутствие повторов слов, наличие транскрипций
и совпадение `words` с `en`.

## Сервис-воркер и обновления

Стратегии: переходы и JSON — «сеть, при отказе кэш»; статика — «кэш с фоновым обновлением».
При любом изменении файлов **поднимайте `VERSION`** в `service-worker.js` (например `v1.0.1`), иначе
браузер продолжит отдавать старую версию из кэша. После обновления страницу достаточно перезагрузить
дважды: новая версия встанет и захватит вкладку.

## Журнал решений (отклонения от ТЗ и почему)

1. **Без сборки.** Чистый ES-модульный JS вместо Vite + React: ноль зависимостей, деплой копированием папки,
   ничего не ломается через полгода. Плата — нет HMR.
2. **Восемь модулей вместо двух.** Расширение объёма по просьбе заказчика: модули 1–8 Spotlight 6.
3. **Хеш-роутинг** (`#/cards`), чтобы работала кнопка «Назад» на Android и не было 404 при обновлении страницы.
4. **Прогресс по элементам, а не счётчиками.** `words: {module1: {mother: {spell, speak}}}`, звёзды вычисляются.
   Иначе «максимум 2 звезды за слово» не гарантировать, а повторное прохождение накручивает счётчик.
5. **Проверка произношения отключена для коротких служебных слов** (`at`, `in`, `on`, `can`, `must`):
   на них распознаватель ошибается почти всегда, ребёнок застревал бы в цикле «попробуй ещё раз».
6. **«Пропустить» в конструкторе и «Закрыть» на микрофоне** — всегда доступный выход, чтобы не блокировать ребёнка.
7. **Строгий режим чтения считается через LCS** (наибольшая общая подпоследовательность), а не «угадай порядок целиком»:
   это честно наказывает перестановку, но прощает выпавшее слово.
8. **Офлайн ≠ микрофон.** Chrome распознаёт речь на серверах Google, поэтому «Проверка произношения» и
   «Проверка чтения» требуют интернета. Карточки, конструктор, тексты и озвучка работают офлайн полностью;
   на микрофонных экранах при отсутствии сети показывается объяснение на русском.
9. **Точка и заглавная буква не обязательны** при сборке предложения: сравнение идёт без пунктуации и регистра,
   но в подсказке напоминается про оформление.
10. **Порог 3★ в чтении оставлен 90%** как в ТЗ. Если на практике окажется строго, поменяйте одну строку
    в `js/match.js` → `starsForReading`.

## Ограничения

- Распознавание речи: Chrome и Edge (Android, Windows, macOS). В Safari и Firefox кнопка микрофона покажет
  понятное сообщение. Нужен интернет и разрешение на микрофон.
- `SpeechRecognition` проверяет факт распознавания, а не качество произношения — это ограничение Web Speech API,
  а не приложения.
- Контент — реконструкция по темам модулей, а не дословный Word List учебника. Точные списки можно
  подставить в JSON.
- Контент и прогресс хранятся на устройстве; при очистке данных сайта прогресс исчезнет.
